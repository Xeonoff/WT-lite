# WT LITE

Браузерный танковый бой с видом сверху (камера под небольшим углом), модульным уроном и рентгеном попаданий в духе War Thunder. Рендер — three.js (r160, лежит локально в `js/vendor`), звук — процедурный Web Audio, без внешних ассетов.

## Запуск

Игра на ES-модулях, поэтому открывать нужно через HTTP-сервер, а не как файл:

- VS Code: расширение **Live Server** → «Open with Live Server» на `index.html` (порт 5501 уже указан в `.vscode/settings.json`);
- или из папки проекта: `python -m http.server 5501` и открыть `http://localhost:5501`.

Нужен браузер с WebGL (Chrome, Edge, Firefox последних версий).

## Онлайн-режим

Кнопка «Онлайн» в главном меню: позывной → подключение → комната (СССР против Германии, свободные места занимают боты) → «Начать бой». Сетап берётся из ангара для нации своей команды. В бою: Enter — чат, Esc — меню (онлайн-бой не останавливается); после выхода можно вернуться в идущий бой тем же сетапом.

Бой считает сервер — тот же код `js/sim`, что и в одиночной игре: клиенты присылают ввод (газ, поворот, точку прицеливания, выстрел, действия), сервер 30 раз в секунду обновляет бой и 15 раз в секунду рассылает снимки состояния и события. Клиент интерполирует чужие машины, свою — экстраполирует по последнему снимку. Противник приходит в снимках только тогда, когда его видит ваша команда.

### Локальный сервер

```
npm install
npm start          # http://localhost:8080 — игра и WebSocket /ws
```

Игру можно открыть прямо с сервера (`http://localhost:8080`) или через Live Server — тогда в поле «Сервер» укажите `ws://localhost:8080/ws` (подставляется автоматически). Проверка сервера без браузера: `node server/smoke-test.mjs ws://localhost:8080/ws`.

### Развёртывание на Render

1. Загрузите проект в репозиторий GitHub/GitLab (папки `node_modules` и `_legacy_v1` в `.gitignore`).
2. На [render.com](https://render.com): **New → Blueprint** и выберите репозиторий — `render.yaml` создаст веб-сервис (Node 20, `npm install`, `npm start`, проверка `/health`).
   Вручную: **New → Web Service**, Runtime Node, Build `npm install --omit=dev`, Start `npm start`.
3. Откройте выданный адрес `https://<имя>.onrender.com` — игра подключится к серверу сама (`wss://<имя>.onrender.com/ws`).

Бесплатный тариф Render засыпает после ~15 минут без запросов: первое открытие занимает до минуты. Сервер раздаёт только `index.html`, `css/` и `js/`; серверный код и конфигурация наружу не отдаются.

## Управление

| Клавиша | Действие |
|---|---|
| W/S, A/D | газ/задний ход, поворот корпуса |
| Мышь, ЛКМ | наводка (в деталь под курсором), выстрел |
| ПКМ (удерж.) | бинокль: камера уходит к прицелу |
| Колесо | масштаб (или смена снаряда — в настройках) |
| 1–4 | снаряды |
| R / T / F | ремонт / аптечка / огнетушитель |
| B | артудар по точке под курсором |
| Tab, X, H, M, Esc | счёт, повтор рентгена, подсказки, звук, пауза |
| Enter | чат (онлайн-бой) |

Если между орудием и точкой прицеливания есть здание, скала, подбитая машина или союзник, прицел становится пунктирным, а в точке удара появляется крест с подписью «ПРЕПЯТСТВИЕ».

В ангаре машину можно вращать мышью (колесо — масштаб, двойной клик — сброс) и переключать вид: «Модель», «Броня» (листы окрашены по толщине; при наведении — толщина, угол к линии взгляда и приведённая броня) и «Модули» (броня полупрозрачная, внутри видны модули и экипаж).

Полный справочник по механикам — в игре (кнопка «Справочник» или F1).

## Содержимое

- 20 машин СССР и Германии, 3 ранга, 4 роли (ЛТ, СТ, ТТ, ПТ-САУ); дерево исследований и сетап из 4 машин.
- Режимы: «Превосходство» 6×6 с ботами, «Оборона рубежа» (волны), «Полигон».
- Карты: «Поля Прохоровки» (река с мостами и бродом), «Зимний городок» (замёрзшая река), «Каменный перевал»; процедурная генерация, погода влияет на обнаружение.
- Модульный урон: экипаж с автоматической пересадкой, пожар только от критического двигателя/бака, перезарядка зависит от заряжающего и БК, поворот — от мехвода; гибель при < 2 живых.
- Корпус собран из реальной схемы лобовых листов (`hullForm.nose` в `Vehicles.js`, например «| \ /» у КВ-1 и «Тигра», «|_ \ /» у Pz.II–IV, «\_ \ /» у БТ-7), с надгусеничными нишами и днищем с ходовой: снаряд не пролетает под корпусом сквозь обе гусеницы.

## Структура

```
js/
  core/     Config, Utils, Events (шина событий), Settings, Profile (прогресс), Input
  data/     Vehicles (20 машин), VehicleBuild (геометрия брони, раскладка модулей и экипажа),
            Shells (снаряды), Maps (биомы, карты, режимы)
  sim/      Vehicle, Armor (баллистика), Damage (заброневое, пожар, детонация), Projectiles,
            Physics, World (генерация карт, A*, видимость), AI, Battle, modes/*
  render/   Scene (three.js), VehicleMesh, WorldMesh, Particles, Effects, Overlay (прицел/метки),
            Xray (схема и рентген), Hangar (осмотр машины), ArmorView (зоны брони), Textures
  audio/    Audio (двигатели, выстрелы, попадания)
  ui/       HUD, Screens (меню, ангар, онлайн-лобби, возрождение, итоги, настройки), Dropdown (выпадающие списки), Reference
  net/      Protocol (общий формат сообщений), NetClient (WebSocket), NetBattle (клиентская реплика онлайн-боя)
  Game.js   связка симуляции, рендера, звука и интерфейса
server/
  index.js  HTTP (статика игры, /health) + WebSocket /ws: лобби и комнаты
  Room.js   комната: команды, сетапы, готовность; авторитетный бой, снимки и события для клиентов
```

Симуляция (`js/sim`) не зависит от DOM и рендера — её запускает и онлайн-сервер, и тесты в Node.

Предыдущая версия игры сохранена в `_legacy_v1/`.
